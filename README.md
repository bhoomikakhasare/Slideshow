# 🖼️ Photo Slideshow using Python

The **Photo Slideshow** is a desktop application developed using **Python** and **Tkinter** that provides an interactive and user-friendly way to display a collection of images in a slideshow format. Designed with a simple graphical interface, the application allows users to browse through multiple photos seamlessly, creating an engaging and organized image viewing experience.

The application loads images from a specified collection and displays them one at a time within the Tkinter window. Users can navigate through the slideshow using intuitive controls such as **Next** and **Previous**, making it easy to browse an entire photo collection. The clean interface ensures smooth image transitions and an enjoyable viewing experience.

This project demonstrates the implementation of Python GUI development, image handling, event-driven programming, and user interaction using Tkinter. It serves as an excellent beginner-friendly project for understanding desktop application development and multimedia handling in Python.

## ✨ Key Features

* 🖼️ Display multiple images in a slideshow format.
* ⏭️ Navigate through images using **Next** and **Previous** controls.
* 🎨 Simple and user-friendly graphical interface built with Tkinter.
* ⚡ Lightweight and responsive desktop application.
* 📂 Supports loading and displaying a collection of images.
* 🖥️ Interactive image viewing experience.

## 🖥️ Output

The application displays a graphical slideshow window where users can:

* View images one at a time.
* Navigate through the image collection using navigation buttons.
* Enjoy a clean and organized interface for browsing photos.
